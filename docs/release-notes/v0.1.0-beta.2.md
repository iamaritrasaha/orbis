# Orbis Beta 2 · 0.1.0-beta.2 — A calmer Linux software experience

Your Linux software, in one place.

Beta 2 focuses on a calmer terminal experience, clearer update workflows, safer
execution, and stronger human-facing presentation.

## Highlights

### A calmer terminal experience

- Compact ORBIS command identity displayed at the top of every command.
- Transient, scrollback-preserving command UI: the working state clears cleanly
  and the final result stays in your terminal history.
- Stable launcher navigation with a selectable command list and live software
  pulse.
- Cleaner handoff between progress output and the final state shown to the
  shell.

### Updates that explain themselves

- Grouped, human-readable update listings by provider family.
- Node.js and Python provider families presented together for clarity.
- Actionable `orbis update --apply` review with executable update candidates
  and clear risk signalling.
- Coverage limitations separated from execution risk so you know what Orbis
  knows and what it does not.
- Update-plan revalidation before mutation ensures the plan you reviewed is the
  plan that runs.

### Safer maintenance

- Administrator authorization restored to the foreground terminal before any
  interactive prompt, so `sudo` never runs from a background worker.
- Blocked or unavailable providers are excluded from executable risk
  calculations; they no longer make an otherwise safe operation appear
  dangerous.
- Normal vs high-impact confirmations are handled distinctly.
- The exact plan is shown before any mutation.
- Conservative provider behaviour retained: Orbis skips or blocks rather than
  guessing when safe impact cannot be established.

### Better history and understanding

- Human-readable operation history with plain-language summaries.
- Relative timestamps (`2 minutes ago`, `yesterday`) in default output.
- Successful records are quieter; they surface only when relevant.
- Detailed and raw records remain available with `--verbose` and `--format=json`.

## Install

```sh
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/iamaritrasaha/orbis/releases/download/v0.1.0-beta.2/orbis-installer.sh | sh
```

Installs to `~/.local/bin` — no `sudo` required to install Orbis itself.
Linux x86\_64 and ARM64 are supported.

Restart your shell or follow the installer's PATH instruction if `orbis` is not
immediately found.

## Upgrade

If you installed a previous user-local Beta release:

```sh
orbis self-update
```

Orbis fetches the release manifest, shows the current and available versions,
asks before downloading, and verifies the SHA-256 checksum and archive
structure before atomically replacing the running binary. The existing binary
is never replaced if any check fails.

Development builds (those with a `.dev.` suffix) intentionally do not
self-update; use the installer or a source build for those.

## Known limitations

- Some providers may report incomplete update information; Orbis surfaces the
  gap rather than guessing.
- Orbis deliberately blocks or skips maintenance when it cannot establish the
  exact safe impact of a planned operation.
- Provider availability depends on the software installed on the host: a
  machine without Flatpak will show Flatpak as unavailable.
